# sketchbook/

Somewhere to play. Exercises, fragments, abandoned openings, "what if" scenes,
monologues, a character just talking for two pages to find their voice.

Nothing here has to be good, finished or in a numbered draft. The draft
protection rules don't apply, so files can be changed or thrown away freely.
When something here turns into a screenplay, it gets its own folder and a
`drafts/draft-01.fountain`.
