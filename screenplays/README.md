# Screenplays

Tendai's screenplays: a creative writing space for drafting, experimenting and
finding voices. The aim is scripts that feel lived in, not written. House rules
are in [CLAUDE.md](CLAUDE.md).

- [`sketchbook/`](sketchbook/) holds loose experiments and exercises.
- [`ear/`](ear/) holds real conversation transcripts, used as a reference for how
  people actually talk.
- [`.claude/skills/`](.claude/skills/) has the screenwriting skills, including
  `imperfect-dialogue`.
